### Lệnh Nhanh (Quick Commands):
- **Cài đặt**: `npm ci`
- **Khởi chạy Dev**: `npm run dev`
- **Seed dữ liệu mẫu**: `npm run seed`
- **Sinh OpenAPI & TypeScript Client**: `npm run generate:openapi`
- **Chạy Unit Tests**: `npm run test`
- **Chạy E2E Tests**: `npm run test:e2e`
- **Build Production**: `npm run build`
